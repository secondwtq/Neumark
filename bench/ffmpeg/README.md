# ffmpeg benchmarks

[FFmpeg](https://ffmpeg.org/) CLI, minimal BOLT-ready build (only the
mpeg4 codec, avi/y4m containers, the null muxer and the file protocol).

## Inputs

Generated by `bench/ffmpeg/setup.sh` (idempotent) into
`intermediates/ffmpeg/`.

| file | generated by | size |
|---|---|---|
| `intermediates/ffmpeg/video.y4m` | `gen_video 1920 1080 950` (deterministic YUV420p plasma) | 3.0 GB |
| `intermediates/ffmpeg/video.avi` | mpeg4 encode of `video.y4m` (setup-time, 1 thread) | 1.8 GB |

Generator source: `gen_video.cpp` (next to these scripts); the built
binary is an intermediate result in `intermediates/ffmpeg/gen_video`.

## Benchmarks

```bash
work/ffmpeg/build-bolt/ffmpeg -y -i intermediates/ffmpeg/video.y4m -c:v mpeg4 -threads 1 -q:v 5 -f avi /dev/null
#   ~20.5 s/iter; mpeg4 encode; -threads 1 after -c:v (single-threaded)

work/ffmpeg/build-bolt/ffmpeg -threads 1 -i intermediates/ffmpeg/video.avi -f null -
#   ~14.3 s/iter; mpeg4 decode; -threads 1 before -i (single-threaded), null muxer
```
