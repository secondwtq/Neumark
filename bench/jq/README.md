# jq benchmarks

[jq](https://github.com/jqlang/jq) CLI, built BOLT-ready.

## Inputs

Generated by `bench/jq/setup.sh` (idempotent) into
`intermediates/jq/`.

`intermediates/jq/big.json` - a deterministic 4M-object JSON document
(`gen_json 4000000`, fixed seed). Generator source: `gen_json.cpp` (next
to these scripts); the built binary is an intermediate result in
`intermediates/jq/gen_json`.

## Benchmarks

```bash
work/jq/build-bolt/jq -c '.[] | select(.value > 500000) | .name' intermediates/jq/big.json > /dev/null
#   ~5 s/iter; filter/select pipeline over the 4M-object document

work/jq/build-bolt/jq -c 'sort_by(.value) | .[-100:] | map(.name) | length' intermediates/jq/big.json > /dev/null
#   ~22 s/iter; sort + slice + map over the 4M-object document
```
