# ImageMagick benchmarks

[ImageMagick](https://imagemagick.org/) `magick` CLI, built BOLT-ready,
using its own `-bench N` (runs the whole pipeline - read + op + PNG encode
- N times internally and reports iterations/sec).

## Inputs

Generated by `bench/ImageMagick/setup.sh` (idempotent) into
`intermediates/ImageMagick/`.

`intermediates/ImageMagick/im_input.png` - a deterministic 4096x4096
plasma image (`magick -seed 42 -size 4096x4096 plasma:fractal`; date/time
PNG chunks excluded so the file is byte-identical on every regeneration).

The `MAGICK_CONFIGURE_PATH` env var must point at the repo's `config/`
dir (`work/ImageMagick/config`); the benchmark scripts set it automatically.

## Benchmarks

```bash
work/ImageMagick/build-bolt/utilities/magick -bench 14 intermediates/ImageMagick/im_input.png -resize 50% /dev/null
#   ~20.5 s/iter; lanczos resample to 50%

work/ImageMagick/build-bolt/utilities/magick -bench 1 intermediates/ImageMagick/im_input.png -blur 0x8 /dev/null
#   ~16 s/iter; gaussian blur radius 8

work/ImageMagick/build-bolt/utilities/magick -bench 2 intermediates/ImageMagick/im_input.png -sharpen 0x2 /dev/null
#   ~18.3 s/iter; unsharp mask radius 2

work/ImageMagick/build-bolt/utilities/magick -bench 6 intermediates/ImageMagick/im_input.png intermediates/ImageMagick/im_input.png -compose Over -composite /dev/null
#   ~21 s/iter; Over-composite of the image onto itself

#   -bench N runs the whole pipeline (read + op + PNG encode) N times internally
```
