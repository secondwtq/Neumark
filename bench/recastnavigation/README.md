# RecastNavigation benchmarks

Recast ships no headless CLI (RecastDemo is SDL/OpenGL only), so the
benchmarks drive the project's own libraries (Recast + Detour +
DetourCrowd, no GUI code) through the harness `recast_bench.cpp`
(build/path/crowd modes).

## Inputs

Generated by `bench/recastnavigation/setup.sh` (idempotent) into
`intermediates/recastnavigation/`.

`intermediates/recastnavigation/recast_city.obj` - a deterministic 512x512 "city"
scene (`gen_mesh 512 city`): terrain heightfield + 145 buildings + 70
floating slabs + 55 walkable ramps, 525k tris, multi-level with overhangs
and slopes. Generator: shared `tools/gen_mesh.cpp`, binary at
`intermediates/tools/gen_mesh`.

The navmesh is built at **cs=0.25 / ch=0.15** - the highest resolution the
scene supports: 62.0k verts / 35.5k polys, right at the solo navmesh's
65,534-vertex cap. The `cs`/`ch` resolution is a trailing optional
argument (default 0.3/0.2).

```bash
bench/recastnavigation/setup.sh        # builds intermediates/tools/gen_mesh + generates recast_city.obj
```

## Benchmarks

```bash
intermediates/recastnavigation/recast_bench build intermediates/recastnavigation/recast_city.obj 4 0.25 0.15
#   ~18.1 s/iter; 4 navmesh builds; cs=0.25 / ch=0.15 resolution

intermediates/recastnavigation/recast_bench path intermediates/recastnavigation/recast_city.obj 2800000 0.25 0.15
#   ~19.4 s/iter; 2.8M findPath queries (seeded); cs/ch resolution

intermediates/recastnavigation/recast_bench crowd intermediates/recastnavigation/recast_city.obj 400 15250 0.25 0.15
#   ~20 s/iter; 400 crowd agents x 15250 frames; cs/ch resolution
```

## Gotchas

* **Poly flags are zero after `rcBuildPolyMesh`.** The function
  leaves `pmesh->flags` to the user ("the user is responsible to fill
  it"); without setting them from the areas (WALK/SWIM/DOOR) every
  `dtNavMeshQuery` returns ref=0 and pathfinding silently finds nothing -
  the build "succeeds" but nothing is ever found. The harness sets them
  after the build. (RecastDemo has no headless CLI - its `main()` takes
  no arguments and needs SDL - hence the harness uses the raw
  Recast/Detour APIs and its own ~40-line .obj parser.)
* **Generated-scene pitfalls.** (a) triangle winding: a downward
  normal grid marks nothing walkable and the build silently produces an
  empty navmesh (0 polys, no errors); (b) the solo navmesh format caps at
  65535 vertices AND polygons (`rcBuildPolyMesh` fails with "too many
  vertices"), which bounds the scene size; (c) pre-sized vectors made
  `push_back` append beyond the written region, silently zeroing the city
  geometry; (d) when the distance field clamps to its 0xffff sentinel, the
  watershed `level` computation wraps to 0 and assigns NO regions -
  another silent empty-navmesh path; (e) `rcContext(false)` in a logging
  subclass constructor DISABLES logging - the harness uses `rcContext(true)`
  (this is what finally surfaced "Too many vertices 66255").
