# Graphviz benchmark

[Graphviz](https://graphviz.org/) `dot` CLI, built BOLT-ready with
everything external disabled.

## Inputs

Generated by `bench/graphviz/setup.sh` (idempotent) into
`intermediates/graphviz/`.

`intermediates/graphviz/big.dot` - a deterministic 33x200-node layered
digraph (~6.6k nodes, chain + skip edges) from `gen_dot 33 200`.
Generator source: `gen_dot.cpp` (next to these scripts); the built binary
is an intermediate result in `intermediates/graphviz/gen_dot`.

## Benchmarks

```bash
work/graphviz/build-bolt/dot -Tsvg intermediates/graphviz/big.dot -o /dev/null
#   ~17.5 s/iter; hierarchical layout (dot engine), SVG output discarded
```
