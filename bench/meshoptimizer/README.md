# meshoptimizer benchmarks

meshoptimizer ships no CLI anymore (library only; the old `meshoptimizer`
tool was removed), so the harness `meshopt_bench.cpp` compiles the library
in and drives it directly (simplify/optimize/codec modes).

## Inputs

Generated by `bench/meshoptimizer/setup.sh` (idempotent) into
`intermediates/meshoptimizer/`.

`intermediates/meshoptimizer/mesh.bin` - a deterministic 15.8M-triangle
heightfield mesh (`gen_mesh 2816`, integer-hash value noise, bit-identical
on any platform). Generator: shared `tools/gen_mesh.cpp`, binary at
`intermediates/tools/gen_mesh`.

`gen_mesh` writes standard Wavefront OBJ when the output ends in `.obj`,
else a compact binary format (uint32 nverts, uint32 ntris,
float verts[nverts][3], uint32 indices[ntris][3]) - the meshoptimizer mesh
stays binary because a 15.8M-triangle .obj would be ~550 MB of ASCII and
take seconds to parse every invocation.

All four benchmarks share this one input; only the pass count differs (the
codec is ~100x faster per pass than simplify).

```bash
bench/meshoptimizer/setup.sh       # builds intermediates/tools/gen_mesh + generates mesh.bin
```

## Benchmarks

```bash
intermediates/meshoptimizer/meshopt_bench simplify intermediates/meshoptimizer/mesh.bin 5
#   ~21 s/iter; meshopt_simplify to 50% triangle count

intermediates/meshoptimizer/meshopt_bench optimize intermediates/meshoptimizer/mesh.bin 15
#   ~18.5 s/iter; vertex-cache + overdraw + fetch optimization

intermediates/meshoptimizer/meshopt_bench codec_encode intermediates/meshoptimizer/mesh.bin 65
#   ~18.5 s/iter; glTF mesh codec (index + vertex encode)

intermediates/meshoptimizer/meshopt_bench codec_decode intermediates/meshoptimizer/mesh.bin 500
#   ~19-21 s/iter; decode both buffers, roundtrip verified at startup
```

## Gotchas

* **No CLI anymore; the codec rotates triangles.** The classic
  `meshoptimizer` CLI tool is gone from the repo (library only), so the
  harness compiles the library in and drives the API directly. The index
  codec is lossless only up to *triangle rotation* (it "can rotate each
  triangle to improve compression ratio"), so the harness's roundtrip
  verification accepts the 3 cyclic rotations of each triangle - a strict
  memcmp fails on the second triangle. The vertex codec is exact.
