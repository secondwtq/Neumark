# zstd benchmarks

[facebook/zstd](https://github.com/facebook/zstd) CLI, built BOLT-ready.

## Inputs

Generated by `bench/zstd/setup.sh` (idempotent) into
`intermediates/zstd/`.

| file | generated by | size |
|---|---|---|
| `intermediates/zstd/zstd_corpus.bin` | `tests/datagen -g700M -P50 -s1` (fixed seed) | 734 MB |
| `intermediates/zstd/zstd_stream.zst` | `zstd -3` of a temporary `datagen -g13G -P10 -s2` corpus (deleted after) | ~10 GB |

Both deterministic (fixed seeds) and synthetic; nothing depends on system
content. `intermediates/` is the standalone tree for all generated inputs
and intermediate binaries (gitignored, `rm -rf intermediates` to clean).

## Benchmarks

```bash
work/zstd/build-bolt/programs/zstd -q -T1 -12 -f -c intermediates/zstd/zstd_corpus.bin > /dev/null
#   ~22 s/iter; -T1 single-threaded, -12 max compression, output discarded

work/zstd/build-bolt/programs/zstd -q -d -T1 -c intermediates/zstd/zstd_stream.zst > /dev/null
#   ~8.5 s/iter; -T1 single-threaded, output discarded
```

## Gotchas

* **The multithreading-disabled build ignores `-T0`.** The BOLT build
  uses `ZSTD_MULTITHREAD_SUPPORT=OFF` (the benchmark is single-threaded),
  so `-T0` silently runs single-threaded (24+ min for a 2 GB stream). For
  the one-time stream creation `setup.sh` therefore prefers the system
  zstd (`/usr/bin/zstd -T0 -3`) over the BOLT-built binary.
* **Datagen lives in tests/, not programs/.** `programs/datagen.c`
  is only a library (no main); the CLI is `tests/datagen` (built with
  `make -C tests datagen`). It writes to stdout, so redirect it. `-P` sets
  the compressibility percent and `-s` the seed - both make the inputs
  reproducible.
